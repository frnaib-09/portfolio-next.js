# Foyjur Rafee — Portfolio (Next.js)

My personal portfolio site: about, skills, career, projects, pricing and contact sections, with animated interactions.

## Tech stack

Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · GSAP · Three.js · shadcn/ui

## Highlights

- Animated hero with typewriter effect and preloader
- Scroll-reveal sections and mouse spotlight effect (GSAP)
- 3D visual elements with Three.js
- Projects gallery, pricing cards and contact section
- Component-based structure (`components/`)

## Run it locally

```bash
git clone https://github.com/frnaib-09/portfolio-next.js.git
cd portfolio-next.js
npm install
npm run dev
```
